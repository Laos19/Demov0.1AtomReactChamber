    Class IntentoService

    Ciclo de vida de un intento de nivel: iniciar → registrar pasos → pedir ayudas → responder cuestionario → finalizar.

    Las reglas de negocio viven en PostgreSQL (fn_registrar_paso, fn_usar_pista, fn_finalizar_intento y triggers); este servicio valida propiedad y traduce errores.
